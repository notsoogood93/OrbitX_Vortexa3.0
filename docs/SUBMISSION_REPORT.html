1. Problem Understanding

Public institutions—such as the Pimpri Chinchwad Municipal Corporation (PCMC), Pune Municipal Corporation (PMC), and large higher education campuses—face enormous volumes of citizen complaints and service requests (15,000+ monthly in Pune). These range from emergency infrastructure hazards (burst water mains, electrical cable exposures, road cave-ins) to routine maintenance.

Despite public intake portals (PCMC Sarathi, PMC Care, Samarth eGov), real-world grievance resolution breaks down due to five structural failure modes:

1. The "Limbo" Problem

Grievances enter "In Progress" and stall indefinitely with zero automated penalty, accountability, or progression forcing.

2. Ghost Resolutions

Contractors mark complaints "Resolved" without on-site photo evidence, physical inspection sign-offs, or citizen verification.

3. Silent SLA Breaches

Deadlines expire without notifying supervisors or municipal commissioners because standard databases lack proactive escalation daemons.

4. The Flaky AI Trap

Unconstrained LLM chatbots hallucinate state transitions, approve unauthorized closures, or drop records when given mutation rights.

Critical Failure: Standard databases (SQLite/MySQL) have mutable rows. If an officer delays a water contamination case, traditional logs cannot cryptographically prove when deadlines were missed or if records were tampered with.

2. Proposed Solution: GovFix

GovFix is an institutional-grade, backend-enforced, finite-state workflow engine designed with one immutable governing rule:

"Deterministic Rules Govern Authority, State & Deadlines; AI Informs But Never Silently Overrides."

GovFix replaces ad-hoc ticketing with four tightly integrated subsystems:

  • Deterministic 11-State Finite State Machine (FSM): Formally defines all legal paths. Illegal jumps (e.g. SUBMITTED → RESOLVED) are refused with machine-readable codes (ERR_ILLEGAL_STATE_JUMP) and HTTP 409 Conflict.
  • Backend-Enforced Role RBAC: Every state mutation requires verified authority (CITIZEN, WARD_OFFICER, FIELD_ENGINEER, SUPERVISING_COMMISSIONER, SYSTEM_DAEMON). Unauthorized attempts return HTTP 403 Forbidden.
  • Dynamic Multi-Tier SLA Escalation Engine: Automatically assigns deadlines based on urgency (12h for Hazards, 24h for High, 48h for Standard, 72h for Routine). When deadlines breach, background daemons escalate to Tier-1 (Ward Officer) and Tier-2 (Municipal Commissioner).
  • Tamper-Evident SHA-256 Cryptographic Audit Ledger: Every state change, escalation, and refused attempt is chained into an immutable SHA-256 block sequence, proving 100% mathematical integrity.
  • Virtual Time-Travel Simulation: Interactive controls (+12h, +24h, +48h) allow evaluators to test multi-day escalation workflows in seconds.

4. Constrained AI Integration (FreeLLMAPI + Heuristic Fallback)

GovFix strictly complies with statutory safety requirements: AI is an advisory sidecar with zero state-mutation authority.

  • Multilingual Grievance Extraction: Ingests raw Marathi ("रावेत चौक रस्त्यावर मोठा खड्डा पडला आहे"), Hindi, or English and proposes { category, urgency, ward, draft_response }.
  • Proximity Duplicate Detection: Identifies complaints within 200m in the same ward to eliminate redundant work orders.
  • 100% Offline Resilience: If external APIs or internet are severed, an embedded keyword and regex heuristics engine ensures core operations continue with zero downtime.
